# Day 17

Day 17 covers deploying a real front end and back end to Azure — Static Web Apps for the
Angular bundle, Container Apps for the API — and replacing stored credentials with a
system-assigned managed identity.

## Pieces

- [Deploy to Azure Static Web Apps](deploy-to-azure-static-web-apps/README.md) — the Day 16
  Piece 2 app and the Day 5 Piece 2 API, live, plus a managed-identity token proxy that
  writes to the API with no client secret, certificate, or connection string stored
  anywhere.
