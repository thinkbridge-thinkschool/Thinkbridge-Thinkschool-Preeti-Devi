=== 10. Delete an EXISTING quote, no token -> 403 (not 401 — see verification-log.md "known issue") ===

(the delete endpoint checks resource ownership manually via IAuthorizationService rather than

=== 12. Create quote with a malformed bearer token -> 500 (known issue, NOT fixed — see verification-log.md) ===
$ curl -i -X POST https://day-5-piece-2.bluesky-eec20d45.centralindia.azurecontainerapps.io/api/quotes \
    -H "Authorization: Bearer garbage.invalid.token" -H "Content-Type: application/json" -d '{"author":"x","text":"y"}'
HTTP/1.1 500 Internal Server Error

Root cause (from Application Insights `exceptions` table):
  type: System.FormatException
  message: "IDX12729: Unable to decode the header ... as Base64Url encoded string."
  (an unhandled exception inside the "Internal" JwtBearer scheme's token parsing — a well-formed
   but invalid/expired token is handled correctly as 401; only a token whose header segment isn't
   valid Base64Url triggers this. The real Angular app never sends a token it didn't itself
   receive from a successful login, so this path isn't reachable through normal UI use.)
