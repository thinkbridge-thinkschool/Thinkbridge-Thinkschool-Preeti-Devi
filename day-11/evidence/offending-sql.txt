Offending SQL generated by EF Core:

SELECT "q"."Id", "q"."Author", "q"."AuthorId", "q"."Text"
FROM "Quotes" AS "q"
WHERE "q"."AuthorId" = @author_Id
ORDER BY "q"."Id";

Pattern:
The query is executed once for every author, producing an N+1 query pattern.
With 100 authors, the endpoint performs approximately 101 database queries.
